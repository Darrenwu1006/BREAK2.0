## 1 牌組營運：前中後期策略

（實際曲線：手牌中位 T1–2＝8 → T3–5＝5 → T6+＝2；事件區平均 2.4 張）

### 前期（Turn 1–2）——及川發球是全牌組最高 EV 的兩回合
- 及川〔發5〕＋技能（棄1、+1、對手≥4張棄1）的**強發球開局照舊是必開**（報告 08 黃金時機表仍成立）。33/38 場你都有做，維持。
- 但注意 coach 資料：「選項：托球點數 → 建議：發球點數」15 次——及川 033 的「任意 1 點+1」你有選托球的慣性，**發球回合就該點發球**（5→6 跨過 RCV5 白板線，AI 少留接6 的漏洞仍在，見報告 08 §4）。
- 前期第二任務：**事件區鋪墊**。金田一 005（事件區≥4：攻+2＋對手登場角色攻−2）和国見 007（≥4 抽1；≥6 接+3）的 gate，實測你的事件區 T1–2 平均只有 1.7 張、中期 2.4 張——**這兩張 P03 新卡的 gate 大部分時間是關的**。要嘛前期就刻意把俺も思った/お前達は多丟一張出來鋪 gate，要嘛承認 40 張裡放不進這套 gate（見 §3 調整）。

### 中期（Turn 3–5）——控手節奏與「技能開關」的紀律
- 你的優勢窗口：中期 attack OP 平均 **6.10**（對手 3.62）。及川托＋岩泉攻（棄1 +2）在對手手牌 4–5 張時開技能＝同時觸發「壓到 3 張以下」的連鎖（岩泉鎖補牌、国見 041 吊球 gate）——這條主線你打得很熟。
- **壞毛病在成本端**：「接受效果/付款 → 建議拒絕」**59 次**，是全部模式之最。其中 43 次發生在你最終贏的 Set——所以它不是敗因，而是**勝局裡的浪費**：領先時多棄的每張手牌，都是 Set 2/4 開局的防守真空（Set 節奏數據：Set1 26:12 → Set2 25:13 → Set5 只剩 5:8，長局你會斷氣）。報告 08 §2 的「手牌基數不對等就不開技能」請升級成硬紀律：**對手手牌 ≥6 時，及川/岩泉的棄牌技一律不開**。
- 俺も思った☆ 的時機兩頭錯（19 次「用了→建議 Pass」＋10 次「Pass→建議用」）：垃圾時間開出去空轉、對手回收窗口反而沒開。它的價值 = 對手「非抽牌入手」的懲罰，**開牌時機綁對手的回收動作而不是自己的節奏**（對音駒黑尾/稻荷崎どや前一回合才開，見報告 08 §3 的流程圖，這部分你以前是會的，第三彈版本牌太順手反而退步了）。

### 後期（Turn 6+）——資源終局學
- T6+ 手牌中位 2、OP 掉到 4.72。這套牌的後期贏線是**對手比你先斷**：岩泉 035 的「鎖技能入手」在對手手牌 ≤4 時才有牙齒，所以**中期的控手進度決定後期有沒有贏線**——中期沒把對手壓下 5 張，後期就別戀戰，參考勸棄準則（下）。
- 「AI 勸棄、你續打」66 個段落、你贏下該 Set **36 次（55%）**——你的續打判斷同樣優於 AI 的悲觀建議（同報告 17；準則：續打成本 ≤2 張手牌才打）。
- samples=25 復驗的死局實例（S5T4 vs 伊達，牌庫 0）：你托球位蓋第二張及川 058 追 OP，正解是丟岩泉 035 上托球位（toss0）——**牌庫歸零的回合，OP 已無意義，每張手牌都是下一 Set 的登場權**，丟「這 Set 用不到參數的那張」。

## 2 你 vs 電腦：共同分歧模式

### 你更有前瞻性的（保留）
1. **拉鋸局續打**：55% 逆轉率（66 例中 36 勝）。
2. **技能成本的「總量」判斷**：59 次「建議拒絕」有 73% 在你贏的 Set 裡——AI 對技能收益系統性低估（L0007），你開技能的大方向對，只需要修「對手手牌 ≥6 不開」這一條邊界。
3. **搶攻節奏**：「登場及川→建議不登場角色」14 次多為 AI 過度保守的棄局傾向，你的壓制節奏是這套牌的靈魂。

### 該改的壞毛病
1. **及川三版本混用**（「登場及川→登場及川」34 次、平均 −42%，是單一模式裡勝率差最大的）：033（技能發球手）/ 056（托球回收）/ 058（白板發5托2）功能完全不同。**明確分工：058 站發球位（純數值）、033 留給「要開棄牌技的回合」、056 只在要回收岩泉時上托球位**。033 只有 5 張別當白板燒。（岩泉 035/059 同理，25 次同型分歧。）
2. **渡親治過度上場**：「登場渡→建議登場国見/及川/岩泉」31 次。渡的技能 gate 是「對手 OP≥6」，對手 OP 低的回合他就是張接 5 白板——低壓回合用国見 041/007 接球，把渡留給真正的大球。
3. **勝局浪費技能成本**（見 §1 中期）——它決定你 Set 5 只有 5:8。
4. **事件 8 張全上但 gate 沒鋪**：005/007 的事件區 gate 常年不開（§1 前期），等於帶了兩張半殘卡。

## 3 牌組調整建議

### 已模擬驗證：調整C「萬用體」（牌表見 `decks/青葉城西/第三彈測試_調整C萬用體.csv`）
```
+1 HV-PR-008 岩泉〔發4/攔1/接4/攻3 白板萬用體〕 +1 HV-P03-060 国見〔發2/攔1/接4/托1/攻2〕
-1 HV-P03-059 岩泉（2→1） -1 HV-P01-039 渡親治（6→5）
```
- 思路：用「多區位可站的白板」替換「單一用途卡」，直接壓「未能登場 36 次」；同時把渡 6 張的低壓回合冗餘換成能站攻擊位的身體。
- 模擬結果（vs 實戰對手池 6 套）：formal **+5%**、holdout **+3%**（兩輪都 candidate-better）。**對兩大苦手正中靶心：白鳥澤-三彈 +2.5%/+20%、伊達韋宏 +2.5%/+10%**；trade-off 在音駒（+12.5%/−15%）與稻荷崎（+5%/−15%）——噪訊區間，但方向上「白板變厚、控手變薄」對干擾/回收型會略軟。
- ⚠️ 同樣的模擬效度警語：heuristic 不開技能，控手軸的技能價值被系統性低估，因此「+5%」主要反映身體值與登場合法性的改善，控手端的實戰損失可能比模擬大一點。先上手打 3–5 場再定案。

### 未驗證的手動選項
- **P02-057 岩泉回歸 1–2 張**（對手 ≤3 張時接+7）：對白鳥澤-三彈 1/4 的破洞，這是卡池裡唯一能硬接 OP8 的答案（報告 08 §5 對白鳥沢的核心解）。模擬 +1%（too-close）**但它的價值全在技能，正是模擬最瞎的那種卡**——強烈建議實戰自測，蓋掉模擬結論。可行的刀位：−1 渡（5→4）−1 088。
- **金田一 005 的去留**：如果你不想改變打法去鋪事件區 gate，005×2 可以降 1 張換 PR-017 金田一・国見（雙名分流）；如果想保留，前期就要刻意鋪事件（見 §1）。二選一，別維持現狀的半殘狀態。
