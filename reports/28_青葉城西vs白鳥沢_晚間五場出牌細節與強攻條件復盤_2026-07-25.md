# 青葉城西 vs 白鳥沢：晚間五場出牌細節與強攻條件復盤

> [Codex 2026-07-25] 分析範圍：2026-07-24 晚間至 2026-07-25 凌晨的五場 replay。青葉城西固定使用「第三彈測試_調整C萬用體2」，對手固定使用「白鳥沢-三彈優化」。本報告只處理對局內決策與 gameplan，不修改牌組、規則或 AI。

## 先講結論

- 五場戰績 **2 勝 3 敗，Set 合計 11：13**。樣本不足以判定牌組突然變弱，但足以確認：這個對局的抽牌波動確實會被青葉城西的三段式出牌需求放大。
- 13 個失去的 Set 中，至少 **9 個最後死於無法部署接球，或接球後湊不出完整的接球—舉球—攻擊鏈**。這不是單純「攻擊不夠高」，而是身體張數與角色順序先崩掉。
- 五場共有 27 次青葉攻擊，其中 17 次沒有跨過當時白鳥沢的單張接球上限指標；真正打到 **OP7 以上只有 7 次**。除一手 OP7 仍被額外資源守住外，高 OP 幾乎都能明顯推動 Set 勝利。
- 「把白鳥沢壓到三張就開始強攻」方向沒有錯，但 **三張只能視為壓力窗口，不能視為斬殺線**。白鳥沢三張仍可能是山形＋Semi＋牛島，或兩張山形加事件，角色品質足以完成防守和反打。
- 找到三個可立即修正的明確決策：
  1. 第一場決勝 Set 面對 OP6，手上有三張渡親治卻直接放棄接球；渡親治可棄一張青葉卡，從 R5 升到 DP6 並補一張。
  2. 第四場 Set 1 面對 OP3，手上岩泉 B3，卻先選接球後無合法接球；應直接用岩泉單擋 DP3。
  3. 第五場決勝 Set 面對 OP4，手上國見 R5 可免費守住，卻用岩泉接球並支付 3 Guts 做到過量 DP8；這同時浪費 Guts，也把原本 A3 的岩泉從下一段攻擊鏈拿掉。

## 什麼是運氣，什麼仍能控制

### 波動確實很高

[Codex 2026-07-25] 第二場最能說明問題。青葉拿下 Set 1 後，白鳥沢連續以 Semi 製造 OP6；Set 3、Set 4 即使青葉手上有 8–9 張牌，仍沒有能直接做到 DP6 的接球手，攔網組合也不夠。這類盤面不是靠「打法再保守一點」就能修正。

[Codex 2026-07-25] 第五場 Set 4 面對 OP5，又受到白布對接球角色 -2 的延遲效果。當時國見 R5 也只剩 DP3，岩泉與及川更低，攔網同樣不足。最後選誰接都救不了，屬於可見資訊下的死局。

### 但有三手不該歸因於運氣

#### 1. 第一場 Set 5：渡親治應接 OP6

- 決策位置：replay index 181，Set 5、Turn 2。
- 當時對方 OP6，青葉手牌 8 張，其中有 **3 張渡親治**。
- 實際選擇：不部署接球，直接失去決勝 Set。
- 可行路線：渡親治 R5 登場，棄掉另一張青葉城西卡，技能 +1 到 **DP6**；場上角色皆為青葉時再抽一張。

[Codex 2026-07-25] 這不是需要猜牌序的高難度判斷，而是卡片功能漏看。實戰上只要看到「對方 OP6＋手上渡親治」，就應先停下來檢查技能，不要把 R5 當作必死。

#### 2. 第四場 Set 1：選防守方式前先比一次攔網

- 決策位置：Set 1 尾段，面對 OP3。
- 當時手上有岩泉 B3，但沒有足夠的接球角色。
- 實際選擇：先選「接球」，下一步因無合法接球而直接失 Set。
- 可行路線：先選「攔網」，岩泉單擋即可 **DP3 精準守住**。
- 復盤教練 40 次小樣本中，實際接球路線估計 10%，岩泉攔網約 25%；只把它當方向性證據，不當精確勝率。

[Codex 2026-07-25] 建議形成固定動作：每次對方 OP1–3，按下接球前先掃一次手牌的 B 值。青葉的低接球角色有時反而是足夠的單張攔網。

#### 3. 第五場 Set 5：國見免費接，不要用岩泉過量防守

- 決策位置：replay step 150，面對 OP4。
- 當時手牌包含國見 R5、岩泉 R1／B2／A3、及川與事件。
- 實際選擇：岩泉接球，支付 3 Guts 把 DP 拉到 8。
- 建議路線：國見 R5 免費守住，保留 3 Guts，並把岩泉 A3 留給及川舉球後的攻擊。
- 實際後續是及川舉球＋國見 A0，僅做出 OP1；若保留岩泉，基礎攻擊就能多出 3 OP。
- 復盤教練 40 次小樣本中，岩泉路線約 7.5%，國見路線約 32.5%；同樣只當方向性訊號。

[Codex 2026-07-25] 這手同時犯了兩件事：用昂貴資源做過量防守，以及把高攻擊身體消耗在低接球職責。青葉每一張身體都很緊，角色分工要優先於「能不能靠技能硬接」。

## 為什麼「白鳥沢剩三張」仍不等於可以收頭

以下三個盤面都顯示：手牌數量相同，品質可以完全不同。

- 第四場 Set 1：白鳥沢三張牌中有山形，青葉 OP6 被精準守住，接著青葉斷鏈失 Set。
- 第三場 Set 4：白鳥沢三張是山形、Semi、牛島。青葉 OP5 被山形守住，白鳥沢立即以 OP6 反打。
- 第五場 Set 5：白鳥沢三張包含兩張山形與事件，進攻性不強，但防守品質很高；青葉連續低 OP 仍無法收頭。

[Codex 2026-07-25] 因此目前策略應從「三張＝強攻」改成：

> **三張＝進入斬殺檢查；通過攻擊力、回防與角色鏈三個條件，才正式強攻。**

## 修正版 gameplan：三道鎖

### 鎖 1：這一球真的能造成防守壓力嗎？

- 優先門檻：**OP7+**。
- 若只能做到 OP4–6，至少要有公開資訊支持：山形已大量使用、白鳥沢事件／Guts 不足，或這次攻擊不需要付出完整三張身體。
- OP0–3 不一律禁止，但要能說出交換目的：低成本逼出特定防守、循環手牌，或避免立即失分。若青葉花完接—舉—攻三張，只換掉白鳥沢一張接球，通常是虧的。

### 鎖 2：打完後，下一球靠誰接？

攻擊前先口頭回答：

1. 對方若回 OP5，我手上誰接？
2. 若必須靠渡親治技能，還有哪張青葉卡能棄？
3. 守完後，是否還留有兩個不同名字的身體完成舉球與攻擊？

[Codex 2026-07-25] 若三題答不出來，白鳥沢即使只剩三張，也先不要把所有資源壓進 OP4–6。第三場 Set 4 就是典型：青葉 OP5 沒打穿，自己只剩一張事件，回來的 OP6 完全依賴神抽。

### 鎖 3：不要用錯角色承擔職責

- 有免費精準接球時，不先支付 3 Guts 做過量防守。
- 高 A 身體與高 R 身體同時存在時，原則上讓高 R 接、高 A 攻。
- 對 OP1–3，選接球前先檢查單張／雙張攔網是否剛好足夠。
- 及川舉球後，確認剩下的攻擊角色名字不同；決勝 Set 最後只剩同名及川，會直接斷在攻擊階段。

## 下一輪實戰只測這一件事

[Codex 2026-07-25] 暫時不要再分「激進五場 vs 保守五場」。這個對局的抽牌變異太大，會讓風格標籤蓋過真正的操作問題。下一個五場樣本固定使用同一牌組與同一白鳥沢版本，只執行以下規則：

1. 白鳥沢到 3 張時，先進入斬殺檢查，不自動 all-in。
2. OP7+ 可積極打；OP4–6 需同時保有下一球接手與兩張不同名身體。
3. 每次防守先比較接球與攔網。
4. 有免費足額接球時，不支付 Guts 過量防守。
5. 每個敗 Set 只記一個原因：`無防守答案`、`有答案但漏看`、`守住後角色鏈斷`、`攻擊未過線`。

這樣下一輪能回答的不是模糊的「哪種風格比較順」，而是更有用的問題：

> **三張斬殺檢查能否減少青葉自己先斷鏈，同時不犧牲真正的 OP7+ 收頭機會？**

## 證據邊界

- [Codex 2026-07-25] 五場皆固定青葉與白鳥沢版本，適合比較操作脈絡；但只有五場，不能拿 2：3 直接推論牌組強弱或 matchup 勝率。
- [Codex 2026-07-25] 復盤教練的 40 次抽樣只用來協助排序可疑決策，不把百分比當真實勝率。
- [Codex 2026-07-25] 「17／27 未越過單張接球上限」是壓力指標，不等於完整防守機率；實際仍受攔網、事件、技能、Guts 與手牌角色組成影響。
- [Codex 2026-07-25] 對手三張手牌的實際內容只用於賽後解釋，不應在實戰中當作玩家可知資訊；實戰判斷只能依公開棄牌、場上區域、Guts 與已使用資源。
