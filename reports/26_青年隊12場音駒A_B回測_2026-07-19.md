## 一句話結論

**下週若只能選一版，先選 A「合宿精英－優化」。**

理由不是 A 的 6–0，而是 A 的影山後排攻擊品質較高、攻擊波動稍低、每次攻擊消耗的事件較少；B 的烏養循環確實能運作，但還沒有把「多開事件」轉換成更高的 Set 勝率。原始勝率受到 AI 提前放棄嚴重污染，不能單獨作為選牌依據。

- [Codex 2026-07-19] B 共使用烏養 8 次，代表事件燃料確實被重複利用。
- [Codex 2026-07-19] `おりこうさん` 使用 4 次；其中 3 次成功把烏養拿回並在同回合再用。
- [Codex 2026-07-19] 這 3 次完整循環只贏 1 個 Set、輸 2 個 Set；另 1 次沒有拿回目標，也輸掉 Set。

## 主動放棄：這是本輪最明確的進步

玩家 Set 結束回饋共 48 筆，覆蓋全部 Set。

| 原始計畫 | 次數 | 當前 Set | 有下一 Set時的結果 |
|---|---:|---:|---:|
| 按牌組計畫累積資源 | 15 | 13–2 | 9–5（14 次可觀察） |
| 全力搶 Set | 8 | 8–0 | 1–3（4 次可觀察） |

| 在賭關鍵拼圖 | 2 | 0–2 | **2–0** |

[Codex 2026-07-19] 「為下一 Set 留資源」的 6 次，在下一 Set 全勝；所有仍有合法牌卻主動放棄的決策，下一 Set 合計 10–2。小樣本仍不足以建立固定規則，但已足以反駁「輸掉當前 Set 就等於處理錯誤」。

應保留的判斷順序：

1. 下一 Set 是否已經有完整攻擊鏈。
2. 事件區是否還有燃料。
3. 本 Set 若繼續投入，能否迫使音駒消耗有價值的防守資源。
4. 若只是多丟一張牌、仍無法跨過對手可見的防守上限，就應保留。

## AI 為何會提前投降

### 全局觀察

- 玩家贏下 31 個 Set。
- 其中 20 個 Set 是 AI **仍有合法牌或事件**，卻主動選擇 Lost／不登場。
- 另 1 個 Set 是真的沒有合法牌；其餘 10 個才是實際接球／判定失敗。
- A 比 B 多贏 5 個 Set；兩版的 AI 主動放棄數量剛好也差 4 個，再加 A 多 1 次無合法牌。這使原始 A/B Set 差幾乎無法與 AI 行為拆開。

### 固定狀態重跑的代表案例

| 對局／步驟 | 局面 | 重跑結果 | 判定 |
|---|---|---|---|
| Match 1 / 115 | Set 3、OP0、比賽點接球 | Lost 0%；合法接球約 2.9–7.1% | 現場選 Lost 疑似 wall-clock 搜尋噪音 |
| Match 2 / 98 | Set 3、OP7 | 所有候選皆 0% | 放棄可視為等價合理 |
| Match 7 / 65 | Set 2、OP6 | Lost 2.96%；事件 6.82%；pass 6.39% | tie-break 把 Lost 拉回首選 |
| Match 10 / 154 | Set 4、比賽點發球 | Lost 0%；福永 3.99% | **明確不應直接送掉比賽** |
| Match 11 / 46 | Set 1、OP2 | Lost 22.95%；夜久 24.79% | 1.84pp 差距內被壓力 tie-break 反轉 |

### 根因

[Codex 2026-07-19] `src/ai/coach.ts` 會把 `lost`／不登場與合法牌一起列入候選；`src/ai/ismcts.ts` 的 root tie-break 會把距離最佳解 4 個百分點內的候選視為近似，改用資源壓力分數排序。這個壓力分數沒有排除「立即輸掉 Set 或比賽」的終局動作，因此 Lost 可能因為手牌被保留而取得較高壓力分數。

這不是每次放棄都錯：當 OP7–10 而 AI 最高合法 DP 只有 0–5，保留資源是合理的。真正的 bug 邊界是：**仍有非終局行動，而且 Lost 並非同等最佳時，root tie-break 不應把立即終局的 Lost 反轉成首選。**

> [Codex 2026-07-19] 本輪只診斷，未修改 AI。建議另開窄幅修正：終局 Lost 不參與壓力 tie-break，除非所有非終局候選也已等價失敗；再用上述固定 Replay 狀態與 benchmark 驗證。

## Undo 與「變穩」的限制

- 12 場中 7 場使用 Undo，共 46 次回溯。
- 前 6 場 5 次，後 6 場 **41 次**。
- Replay 只保留最後採用的 canonical branch，無法看到被撤銷的原始失誤。

[Codex 2026-07-19] 所以本批可以證明「最後採用的打法更有計畫」，不能直接證明「不靠修正也變得更穩」。如果目標是估計下週實戰失誤率，下一批應另跑至少 6 場 No Undo，與允許 Undo 的學習局分開標記。

## 已排除的規則疑點

[Codex 2026-07-19] 影山 `バックアタック(4)` 後被研磨降低攻擊值不是 bug。官方 Q1478 的順序是先設定攻擊值，再吃研磨的攻擊參數 -2，最後才計算 OP；「自己的 OP 不會被降低」保護的是已計算完成的 OP。該 Replay 的 4→古森 +1→研磨 -2→烏養 +1，最後攻擊值 4、合計 OP6，與規則一致。

## 下週前的決策建議

1. **正式版先用 A；B 降為研究版。** A 的優勢來自後排攻擊品質與較低事件成本，不採信被 AI 放大的 6–0。
2. **R5／R6 古森先維持各 3。** 本批沒有足夠證據支持再換張；A 的 6 次後排中 4 次仍使用 R5 古森。
3. **影山後排以 OP7 作為實戰門檻。** OP5–6 可在低成本或逼關鍵資源時使用，不應只因能開技能就自動開。
4. **保留「放棄當前 Set」的能力，但要寫出下一 Set 的三張鏈。** 若說不出下一個 Set 的舉球、攻擊與事件燃料，便不是計畫性保留。
5. **下一批分開記錄學習局與測試局。** No Undo 才能估實戰穩定度；允許 Undo 的局用來找最佳路線，兩者不能混算。

- [使用者 2026-07-19] 後續報告希望以機率與期望值判斷出牌是否不合理，並把決策品質與好／壞結果分開；低期望值卻成功可能是觀察到新訊號，也可能只是猜對。
