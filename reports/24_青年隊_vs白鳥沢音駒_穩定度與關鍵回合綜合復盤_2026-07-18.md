# 青年隊 vs 白鳥沢／音駒：穩定度與關鍵回合綜合復盤

> [Codex 2026-07-18] 分析類型：M8 Replay Review／Coach Mode。主樣本為 2026-07-18 今日 10 場青年隊對局；另以 2026-07-17 對白鳥沢 6 場作 matchup 敏感度檢查。本文使用完整 replay state 做賽後全觀分析，但會明確區分玩家當下可知資訊、賽後才能看到的對手手牌，以及低樣本模擬訊號。

## 0. 先講結論

你感覺到的「贏局超順、輸局一塌糊塗」是資料裡真實存在的現象，但原因不是單純的攻擊力浮動。

青年隊更接近一套 **防守門檻型的三段 combo 牌組**：

1. 先用古森、佐久早、千鹿谷與接球事件守住；
2. 每個 Set 都要重新拼出不同名稱的 receive → toss → attack；
3. 身體鏈和 Guts 同時存活時，再由影山 BA／星海把 OP 拉到 7–10 終結。

因此它不是每回合都穩定施壓的純進攻牌。它的上限很高，但只要其中一個門檻斷掉，手上即使還有 4–5 張牌，也可能沒有一條合法路線。

今日 19 個失 Set 中：

| 失 Set 原因 | 次數 | 占比 |
|---|---:|---:|
| 無法完成登場 | 16 | 84% |
| 判定失敗 | 2 | 11% |
| 主動 Lost | 1 | 5% |

更關鍵的是，對音駒的 18 個失 Set中，有至少 8 個不是被高 OP 打穿，而是倒在 OP0–4、或接到球後無法繼續托球／攻擊。真正不穩的是「功能手牌下限」，不是攻擊上限。

目前兩個版本的領先訊號也很清楚：

- `ユース-合宿精英-優化`：今日對音駒 4–0、Set 12–5。
- `ユース-烏養測試`：今日對音駒 1–4、Set 10–13。
- 但兩者穿過音駒最佳單卡接球值的攻擊比例幾乎相同：優化版 46%，烏養版 47%。

也就是說，優化版今日贏得較多，主要不是因為「打得更大」，而比較像是它更常讓三段身體鏈活到下一次進攻。樣本仍小，這是強烈的領先假說，不是最終定案。

## 2. 為什麼會出現「順到底／崩到底」

### 2.1 第一層門檻：不是牌數，而是三個不同名字

一個看似五張的手牌，可能實際只有一個可用身體：

- 兩張同名角色不能連續負責托球與攻擊；
- attack-only 事件在防守回合不能補接球身體；
- toss-only 引擎事件不會自己抽身體；
- 高 R 角色若被提早拿去做 A0 攻擊，下一輪可能失去唯一接球點。

今日代表終局裡，多次出現「4–5 張在手，但實際沒有三段鏈」：

- 兩個角色＋三個事件；
- 一個角色＋三個事件；
- 兩張同名宮侑＋兩個事件；
- 接球成功後只剩同名角色，無法合法托攻。

所以青年隊的真正資源單位不是一張牌，而是一條 **R 名字／S 名字／A 名字**。

### 2.2 第二層門檻：事件是潤滑，也可能是黏住手牌的東西

烏養版的變動不是單純多一張強牌：

- `佐久早聖臣（B3/R4/A3）` 4 → 3：少一張可跨角色的萬用身體；
- `古森元也（R6/A0）` 3 → 4：接球上限增加，但功能更專一；
- `ドンッ` 2 → 1、`周りの上手さに引っ張られる` 1 → 0：少兩個可在相關階段抽牌／轉換的事件槽位；
- 新增 `烏養 一繋`：進攻回合抽 1、攻擊 +1，條件滿足再 +2；
- 新增 `プレーは大分 おりこうさんよな`：托球階段設定 S2，並可回收 attack-only 事件，但本身不抽牌。

這個交換提升了接球天花板與已成形引擎的爆發，卻降低萬用身體密度；當 S 鏈沒有在線時，`おりこうさん` 不能把手牌往前推。

今日烏養版 14 個失 Set 的終局手牌中，`おりこうさん` 出現 8 次。它是目前最值得追蹤的「卡手嫌疑」，但不能只靠終局共現就判定必須拔掉：還要記錄它被打出後實際回收了什麼、回收牌是否在同 Set 轉成勝利。

### 2.3 第三層門檻：贏 Set 後的手牌稅

今日共有 17 次「贏下一個 Set、且比賽尚未結束」的轉場，其中下一 Set 輸掉 10 次，比例 59%。

Set 位置分布：

| Set | 勝–敗 |
|---|---:|
| Set 1 | 8–2 |
| Set 2 | 5–5 |
| Set 3 | 6–4 |
| Set 4 | 5–4 |
| Set 5 | 2–3 |

這與既有 33 場青年隊報告的 Set 1 強、Set 2 明顯下滑一致。青年隊常用掉多張牌完成高 OP 收尾，贏下 Set 的同時，也可能把下一 Set 的三段鏈拆空。

因此「這一球能不能打到 10」不是唯一問題；還要問：「打完 10 之後，下一 Set 還剩幾個不同名字？」

## 3. 對白鳥沢：為什麼目前較容易贏

### 3.1 對手資源輪廓

白鳥沢的威脅比較明確：

- 牛島等角色能穩定形成 OP6–8；
- 山形是 R6 接球牆；
- 高壓球若沒有防守事件或 R6 身體，會直接穿透。

但青年隊的核心防守剛好能對上這個門檻：古森 R6，加上雲雀田、火燒等接球增益，可把 DP 推到 7–9。守住後，影山／星海能在對手 R6 已耗掉或手牌下降時打出 OP7–10。

白鳥沢是在問：「你這次 DP 能不能到 7？」青年隊常有清楚答案。音駒則持續問：「你下一次還有三個不同名字嗎？」後者更容易暴露青年隊的結構下限。

### 3.2 為什麼能贏

- 今日 step 79：青年隊以 DP8 接住 OP8；下一段資源仍能延伸。
- step 85：星海接手完成 Set 2。
- step 184：宮侑技能在線、星海把 OP 拉到 10；對手雖握山形 R6，仍無法跨過。

勝利公式不是盲目競速，而是：

> 用剛好足夠的 DP 接住白鳥沢高壓 → 保住可托攻的不同名字 → 等 R6 牆消耗後，用 OP7–10收尾。

### 3.3 為什麼仍會輸 Set

今日 Set 3 的 step 149，青年隊手上是 `ドンッ`＋星海 R5，對面 OP5。表面上像是差一點接球，但即使星海接住，後面也沒有托球與攻擊身體，屬於結構性死局。

更早的 step 135，古森 R6 被拿去當 OP2 的攻擊身體。這不一定是錯，但值得檢討：當手牌已薄時，用專職高 R 身體換一個低壓攻擊，是否把下一輪唯一防守門檻先花掉了？

## 4. 對音駒：為什麼特別難纏

### 4.1 音駒不是只靠高 DP，而是靠延長交換

音駒常見的實際防守資源包括：

- 夜久 R5／6；
- 犬岡、山本等 R5 身體；
- `これが“繋ぐ”` 類事件可把接球提高到 R7 門檻；
- block return 即使只有 OP0，也會強迫你再付一次三段身體鏈。

今日青年隊對音駒共 58 次攻擊，只有 27 次高於對方當下最佳單卡接球值，比例 46.6%。也就是說，超過一半攻擊本來就比較像交換牌，而不是直接終結。

音駒最麻煩的地方，不只是能接住 OP5–6，而是它接住之後用 OP0–4 把問題丟回來。青年隊若只剩兩個不同名字，就會輸給一顆數字很小的球。

### 4.2 為什麼能贏

代表終結局面顯示，應看對手「最高可用 R」，而不是只看手牌張數：

- 16:19 step 170：對手手牌 5 張且全是角色，但最佳實際接球只有犬岡 R5；星海 OP10 完成終結。
- 16:50 step 190：對手手牌 3 張，其中只有犬岡 R5可守；星海 OP10完成終結。

這些勝局的共同點是：

1. 青年隊的三段鏈仍完整；
2. Guts／技能足以把星海推過 7；
3. 音駒高 R 身體或接球事件已經耗掉；
4. 最後一擊不再跟 R5做一換一，而是直接跨牆。

### 4.3 為什麼會輸

對音駒 18 個失 Set中：

| 原因 | 次數 |
|---|---:|
| 無法完成登場 | 15 |
| 判定失敗 | 2 |
| 主動 Lost | 1 |

其中至少 6 次終局對面 OP0，另有 2 次是接球成功後無法托球。這八次都不是音駒用高攻擊打穿，而是它把交換拖到青年隊的名稱鏈先斷。

最極端的例子是 13:45 step 46：音駒手牌已經是 0，回來的也只是 OP0；青年隊仍因為只剩事件與單一身體，接完後無法形成托攻而輸。這直接推翻一個危險直覺：

> 對手空手，不代表這個 Set 已安全；如果自己沒有三段鏈，OP0 仍然能殺人。

## 5. 烏養版與優化版：目前真正的差別

### 5.1 不是攻擊穿透率

| 版本（對音駒） | 攻擊次數 | 高於對手最佳單卡 R | 比例 |
|---|---:|---:|---:|
| 烏養測試 | 32 | 15 | 47% |
| 合宿精英優化 | 26 | 12 | 46% |

兩者幾乎一樣。優化版今日 4–0，不是因為它更常「一拳穿過」。

16:15 的 3–0甚至只有 73 個 replay step、青年隊共 3 次攻擊，沒有一次在理論上高於對手最佳單卡 R；音駒也沒有花 Guts。這場主要反映對手抽牌／身體鏈低點，不能用來證明優化版必然更強。

### 5.2 比較可信的領先假說

優化版多一張可跨 R/A 的佐久早，且保留更多可抽牌或跨階段使用的事件；烏養版則多一張專職 R6 古森與一張不抽牌的托球引擎。

因此目前最合理的假說是：

> 烏養版讓「已經順起來的局」更能把進攻拉高，但也讓「還沒拼好三段鏈的局」更容易握著專職牌與事件一起死；優化版不是上限特別高，而是功能牌密度較平均。

需要用更多交錯測試驗證三件事：

1. 烏養版是否真的更常打出 OP9+；
2. 它是否同時提高 no-deploy 失 Set率；
3. `おりこうさん` 的實際成功回收率，能否補回它占用的身體／抽牌槽。

## 6. 與青葉城西相比，青年隊為何更有「斷崖感」

今日青葉城西樣本為 6–1、Set 19–12；對音駒 4–0、Set 12–6。由於對手版本與樣本配置不同，不能直接拿勝率判優劣，但營運結構可以比較。

青葉城西也會因身體鏈與同名限制輸 Set，可是它的及川、國見、岩泉等資源有更清楚的手牌整理、回復與固定終結路徑。玩家比較容易回答：「這張牌下一步要去哪裡？」

青年隊的角色更像多個門檻零件：

- 古森守數字；
- 宮侑／影山負責托球與技能條件；
- 星海負責終結；
- 事件分散在 receive、toss、attack 不同窗口。

當零件恰好對上，它會像一台完整機器；錯一個名字或階段，剩餘牌的牌面強度再高也不能互相替代。這就是你感受到「青葉城西比較穩，青年隊勝敗更兩極」的結構來源。

| 音駒 15:45 step 165 | 已接住 OP5；手上古森、古森、佐久早，卻不托球 | **最明確可避免回合**；佐久早托球的 40-sample估值約高 25pp | 是否把「攻擊只能 OP0」誤認成沒有繼續價值？ |
| 音駒 15:45 step 200 | 面對 OP7，手上最高 R6且無接球增益 | 40-sample 無顯著替代線 | 這是防守上限，不應只怪最後一步 |
| 音駒 16:01 step 125 | `おりこうさん`＋兩張同名星海，位於托球窗口 | 托一張星海後，另一張同名不能攻擊 | 同名終結手應如何提前拆開使用？ |
| 音駒 16:50 step 74 | 兩張同名宮侑＋兩事件，面對 OP5 | 40-sample 無顯著替代線 | 手牌四張但功能鏈近乎為零 |
| 音駒 16:50 step 153 | 千鹿谷 R0＋古森 R5＋`ドンッ`，面對 OP6 | 40-sample 無顯著替代線 | 事件未對到正確接球門檻 |
| 音駒 16:19 step 170 | 對手 5 張但最佳實際 R5；星海 OP10 | 正確終結窗口 | 應算最高 R，不應被對手牌數嚇到 |
| 音駒 16:50 step 190 | 對手 3 張且最佳實際 R5；星海 OP10 | 正確終結窗口 | 高 OP 應保留給「跨牆」而非普通交換 |

最值得先談的是 step 165，因為它不像其他案例是抽牌死局：當下明明存在合法三段延伸，卻因為下一擊數字低而提前放棄。對音駒而言，OP0也能迫使對方再交一個身體，延續本身就是資源交換。

## 8. 用來刺激判斷的問題

### 8.1 三段身體鏈

1. 每個 Set 開始時，你能不能立刻指出手上預定的 R、S、A 三個不同名字？
2. 如果其中一張必須拿去支付或觸發效果，替補名字是誰？
3. 你現在看到的是「五張手牌」，還是「一條鏈＋兩張不能用的牌」？
4. 你打出接球角色前，有沒有先確認剩下兩個名字能合法托攻？
5. 當下一擊只能 OP0時，你是在判斷「不能贏」，還是誤把它判成「不值得繼續」？
6. 你是否願意用 OP0交換音駒一張 R5，替下一次星海創造窗口？

### 8.2 事件使用與卡手

7. `おりこうさん` 留在手上時，當下真的有 S 身體和可回收的 attack-only 事件嗎？
8. 它回收的事件，是否在同一 Set真正轉成 DP／OP，還是只是讓手牌看起來更多？
9. 它若連續兩個窗口沒有合法價值，是否已經是一張負資源？
10. 你在死亡邊緣握著雲雀田事件時，為什麼選擇 pass，而不是先 draw 1找身體？
11. 進攻事件留在防守手牌裡時，你有沒有把它錯算成「還有一張資源」？
12. `ドンッ` 與 `周りの上手さ` 的 draw 1，是否比額外的數值上限更常救到斷鏈？

### 8.3 高 R 身體與 Guts

13. 古森 R6拿去做 A0／低 OP攻擊前，你下一輪還有第二個 R5+嗎？
14. 這次多花 Guts把 OP從 5推到 6，真的能跨過音駒的牆，還是仍然只換一張牌？
15. 如果不能跨牆，這些 Guts留給下一次星海 OP9是否更有價值？
16. 你目前追求的是「這一球最大」，還是「兩個 Set合計的資源效率」？

### 8.4 讀對手資源

17. 音駒的夜久、犬岡、山本與接球事件各已露出幾張？
18. 對手有五張牌時，最高可用 R到底是 5、6還是 7？
19. 對手手牌歸零時，你自己的三段鏈是否仍完整？
20. 白鳥沢的山形 R6若還沒露出，你的 OP6是在終結，還是在送交換？
21. 哪一個回合開始，對手的手牌張數已不重要，真正重要的是最高 R已經下降？

### 8.5 你要測的「穩定」究竟是什麼

22. 你願不願意用較少的 OP10，交換更低的 no-deploy 失 Set率？
23. 一套牌 3–2贏但有兩個完全不能玩的 Set，和另一套 3–1贏但每 Set都有合法鏈，哪套才叫穩？
24. 你要以 Match勝率、Set勝率、首個斷鏈時間，還是「可操作回合比例」作主指標？
25. 烏養版輸的時候，你最常覺得缺的是接球數字、不同名字，還是能把事件換成身體的抽牌？
26. 你對青葉城西的安心感，來自牌表本身，還是因為你更熟悉它的固定資源路線？

## 9. 接下來幾天怎麼測，才能知道哪套真的穩

建議先凍結兩份牌表，不急著改牌，採交錯測試：

1. 同一天依 A–B–B–A 或 B–A–A–B順序輪替，降低熟悉度與疲勞偏差；
2. 音駒官方牌組作主壓力測試，白鳥沢分開記錄；
3. 每版本至少累積 10 場對音駒，或至少 30 個 Set，再做第一次選版；
4. 每個失 Set只多記一個主因：`R門檻`、`S/A斷鏈`、`同名鎖死`、`事件卡手`、`主動放棄`；
5. `おりこうさん` 額外記三件事：何時上手、是否打出、回收牌是否在同 Set產生價值；
6. 每場記「贏 Set後下一 Set是否斷鏈」，確認 59%是否只是今日波動。

真正適合下週日的版本，不必是平均 OP最高的，而應是：

- no-deploy 失 Set率較低；
- OP0–4時仍能完成三段鏈；
- 贏 Set後不容易立刻空轉；
- 對手高 R耗盡時，仍有星海／影山的終結路線。

## 10. 暫定判斷與停止點

### 目前可信度較高

- 青年隊的兩極化主要來自三段名稱鏈與跨 Set手牌稅，不是攻擊力不足。
- 音駒藉由低 OP回傳反覆收取身體稅，比白鳥沢的高 OP門檻更克制青年隊。
- 優化版今日穩定度領先；領先來源較像功能身體密度，而非攻擊穿透率。
- 15:45 step 165 是今日最明確的可避免失誤：低 OP仍值得延續交換。

### 仍待驗證

- `おりこうさん` 是真正降低穩定度，還是目前尚未掌握正確使用窗口。
- 烏養版在真人對局中，讀到對手事件密度後的攻擊上限是否比 AI 樣本更有價值。
- 優化版 4–0有多少來自牌表，有多少來自音駒抽牌低點。

### 本輪刻意不做

- 不修改兩份青年隊牌表；
- 不啟動 Deck Optimizer；
- 不把問題直接收斂成最終口訣；
- 不更新 lessons。

下一階段應先由你補上關鍵回合的主觀意圖：你當時在算什麼、怕什麼、是否知道仍有合法線。討論完成後，才把共同確認的判斷壓成對白鳥沢與音駒各自的營運要點與口訣。
