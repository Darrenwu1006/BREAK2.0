## 一句話結論

**你的青葉城西對音駒打法已經形成可重複的主線：低成本鋪墊、OP7+ 收割、必要時放掉當前 Set；目前最值得修的不是牌組，而是幾個可避免的時序錯誤與低壓回合的資源浪費。**

不過，9–1 不能直接視為乾淨勝率。音駒 AI 在這批對局中系統性過度加防，另有兩個可重現的錯誤防守路線；它確實降低了對手的手牌與 Guts 品質，也送掉至少一個本來可繼續的決勝回合。

## 猶豫線追蹤

### 1. 「要用岩泉技能前，防守事件應先開」——支持，屬可直接修正的時序

[Codex 2026-07-21] M2 Set 1 #36，你在接球 free window 手上是：`お前達は 強いよ`、岩泉、及川。你選 Pass；之後依序登場及川、岩泉，再把唯一手牌 `お前達は 強いよ` 當岩泉成本棄掉，最後手牌歸零。

- 玩家可見資訊：事件當下合法，能抽最多 1 張；而你已經知道稍後想支付岩泉的 1 張手牌成本。
- 替代線：先把事件移到事件區並抽 1 張，再登場及川／岩泉，最後看完新牌後決定棄哪張。
- 全知結果：實際線把事件直接送進棄牌，下一回合雖接到 OP0，卻無法完成後續登場而 Lost。
- 判定：**支持。** 這不是結果論；先抽再付成本保留更多資訊，且事件本來就在實際線中被棄掉。

> [Codex 2026-07-21] 可執行修正：已知本回合稍後要付手牌成本時，先檢查目前 free window 是否有「本來就會被丟掉、且能補牌」的事件。

### 2. 「Set 1 習慣開及川，可能反而害自己」——情境限定；M10 這次不該開

[Codex 2026-07-21] M10 Set 1 #19，及川技能把托球 1 提到 2、讓對手 4 張手牌棄 1，最終攻擊由 OP4 變 OP5。當時你還有渡、岩泉、金田一與另一張及川，支付成本會削薄下一條角色鏈。

- 玩家視角：對手手牌 4 張，但未知防守內容；OP5 只有在跨過防守上限時才是直接取 Set 的提升。
- 全知結果：對手實際握有 R6 夜久；OP4 與 OP5 都不能直接穿防。
- 方向性 PIMC：固定該盤面重跑，拒絕技能約比接受高 **6.3 個百分點**；數字只作方向，不視為精確勝率。
- 判定：**支持你的懷疑。** 這個盤面不應因「Set 1 習慣」自動開技能。

> [Codex 2026-07-21] 暫定口訣：Set 1 的棄牌及川先問「+1 是否跨防守門檻？」若只是 OP4→5、又會拆下一條三職鏈，就先不開。

### 3. 「洗牌及川這次拿 Set 機率很高」——支持，是好技能時機的正例

[Codex 2026-07-21] M2 Set 3 #157，PR 及川支付 3 Guts：托球 +2，並把音駒 6 張手牌洗回、改抽 4 張；接著 `俺も思った☆` 再加托球，形成 OP7。

- 玩家可見資訊：這一手同時跨過攻擊門檻，並確定把對手 6 張資源壓成 4 張。
- 全知結果：OP7 拿下該 Set。
- 方向性 PIMC：接受技能為首選。
- 判定：**支持。** 與 M10 Set 1 的差異不在「及川能不能開」，而在這次兩個效果都改變勝負結構：OP 達 7、對手手牌確定下降。

### 4. 「沒及川時只能先打、累積資源」——支持，但要把低 OP 分成鋪墊與空耗

[Codex 2026-07-21] M1 Set 3 缺及川，實際只打到 OP2；你標記為留資源，該 Set Lost，下一 Set 以 OP3、OP4 鋪墊後 OP6 收下比賽。全批 5 次 `save-for-next-set` 的下一 Set 都贏。

- 判定：**支持計畫性放 Set，不支持無條件出低 OP。**
- 有價值的低 OP：便宜建立 Guts、迫使音駒登場、保留下一 Set 的及川＋異名攻擊＋事件。
- 空耗的低 OP：為了「有攻擊」而交高價值角色／進攻事件，對手基礎 R5 已足夠且不需付重要資源。

### 5. 「M10 前一回合應該接球，不該用 OP1 攔網」——支持

[Codex 2026-07-21] M10 Set 2 #75，對手 OP1；你手上是回收事件、B1／T1／A2 及川、R5 國見。實際用及川單張攔網成功，只回 OP0，立刻把主動權交回音駒；音駒下一輪做出 OP6，你只剩國見 R5，最終 Lost。

- 玩家可見資訊：接球與攔網都能過 OP1；接球會抽牌並保留及川作托／攻，攔網則消耗最靈活的角色且只製造 OP0。
- 判定：**支持。** 這裡不是比較 DP 是否足夠，而是比較哪條路保留完整反擊鏈。

> [Codex 2026-07-21] 可執行修正：面對 OP0–1，若「接球後能完成接—托—攻」，優先接球；不要為了省一張 R5 接球者而用萬用及川做無壓力攔網。

## 目前打法的強項

### OP7+ 已是可靠的收割層

[Codex 2026-07-21] 62 次攻擊中只有 17 次達 OP7+，但 17 次全部位於最後由玩家拿下的 Set。這不代表「每 Set 強行打 7」，而是支持既有兩段式策略：

1. 第一波用 OP4 左右鋪 Guts、逼音駒展開或確認防守線。
2. 第二波在手牌、角色鏈與事件齊全時打 OP7+ 收割。

M2 PR 及川 OP7、M3 OP9／8、M6 OP9／9、M10 OP10／7 都是乾淨案例。相反地，OP0–3 共 14 次；這些回合必須能說出「拿到什麼資源」或「保留了什麼下一波」，否則就是優先檢討區。

### 計畫性放 Set 已經不是猜拳

[Codex 2026-07-21] 5 次明確 `save-for-next-set` 都輸當前 Set、贏下一 Set。這批資料支持你保留這項能力，尤其音駒發球壓力較低時。決策仍需先寫出下一 Set 三件事：

1. 誰接球。
2. 誰托球。
3. 誰以不同卡名攻擊，以及 OP7 的增益來源。

答不出來時，「留資源」仍可能只是把問題延後。

### 國見 4 張目前不該減

[Codex 2026-07-21] 國見在 M1、M2 的自由文字中被你主動點名，並在多場提供 R5 與補牌安全網。這批沒有出現「國見過量卡死」的跨場訊號；在長局牌庫會歸零的環境下，4 張帶來的可見穩定度高於目前任何減張理由。

## 長局風險：不是火力不足，而是有效資源密度下降

[Codex 2026-07-21] 四場打到第 5 Set 時，玩家牌庫依序只剩 1、0、0、1 張；唯一敗局 M7 同時手牌 0。M8 雖然也牌庫歸零，但仍有 3 張手牌並追回比賽，說明「牌庫薄」本身不是敗因，真正差別是終局還剩多少合法角色鏈與事件燃料。

目前最值得觀察的不是再加火力，而是：

- OP0–3 是否用了不可替代的及川／岩泉。
- 防守成功後是否仍有異名托攻鏈。
- `お前達は 強いよ`、回收事件是否在支付成本前先創造資訊與事件區價值。
- 已經決定放 Set 時，是否仍多付了一個技能或事件成本。

## AI 異常診斷

### A. 不必要加防是系統性現象，不是單一體感

[Codex 2026-07-21] 十場共有 61 次 AI 接球登場。以「角色剛登場、尚未使用 optional 技能／事件時的基礎 DP」對照當前 OP：

- **26/61** 次在基礎 DP 已足夠時，AI 仍使用至少一個 optional 技能或事件。
- 其中 **11/61** 次支付明確技能成本：**4 次棄 1 張手牌、7 次支付 Guts**。
- 事件有時能抽牌、堆事件區或改善後續，不把 26 次全部定罪；但 11 次付費加防已足以確認你觀察到的問題。

代表案例：

| 場次 | 局面 | 實際行為 | 判定 |
|---|---|---|---|
| M9 S2 T2 | 夜久基礎 R5 vs OP1 | 棄 1 張手牌升 R7 | 明確過度加防 |
| M10 S2 T2 | 夜久基礎 R5 vs OP5 | 棄 1 張升 R7，再開事件到 R8 | 基礎已成功，手牌成本無必要 |
| M10 S2 T6 | 夜久基礎 R5 vs OP0 | 支付 3 Guts、抽 1、升 R7 | 有抽牌收益，但以 3 Guts 換取完全不需要的 DP |
| M4 S3 T2 | 夜久基礎 R5 vs OP1 | 付 3 Guts並連開事件，最後 R10 | 極端過防 |

### B. 為何搜尋會偏好開技能

[Codex 2026-07-21] `src/ai/ismcts.ts` 的 `rootDecisionPressureScore(...)` 對技能確認有固定偏好：接受 `+0.05`、拒絕 `-0.05`。當兩候選落在 live root tie-break 的 4 個百分點近似區間時，這個 0.10 分差會主動把「開技能」推到前面。

固定重跑 M10 夜久 R5 vs OP5：3 個 seed、每個 3000 iterations，拒絕技能的平均值都略高於接受約 0.5–0.8 個百分點，但最終仍由 pressure tie-break 選擇接受。這使「基礎 DP 已足夠」的情況仍會被技能偏好反轉。

> [Codex 2026-07-21] 工程假說：`effect-confirm` 的技能正向 bonus 缺少「效果是否改變判定／是否有非 DP 收益」的門檻。後續修正應是窄幅 AI policy／tie-break 工作，不動規則引擎。

### C. M4「不確定為何電腦投降」：不是按 Lost，而是選錯防守路線

[Codex 2026-07-21] M4 Set 1 面對 OP6，AI 手上有犬岡 B3、兩張研磨 B2、海 R4。實際先選接球，再用海 R4，判定失敗。

- 固定盤面 3 seed／3000 iterations：攔網候選的 visits 與平均值都高於接球。
- 但差距約 1.4–2.0 個百分點，落在 4pp close set；root pressure tie-break 仍反轉成接球。
- 判定：**你看到的「投降感」成立，但動作型態不是直接 Lost，而是較佳攔網路線被 tie-break 反轉後接球失敗。**

### D. M10 決勝 Set：確實可以攔網繼續，AI 卻兩步後不登場

[Codex 2026-07-21] M10 Set 5 #198，玩家 OP7，AI 手上仍有犬岡、兩種研磨與黑尾。實際流程：

1. defense-choice 選接球。
2. 抽 1 張後，在 deploy-receive 選不登場。
3. 直接輸掉比賽。

替代攔網線以同盤面合法重放：犬岡＋黑尾＋研磨可形成 **DP8 vs OP7，成功後比賽繼續**。

固定 3 seed／3000 iterations 的 SO-ISMCTS 對接球與攔網都估為 0，最後一律選接球；快速 heuristic 反而正確選攔網。這說明：

- 7/19 的「立即 Lost 不進 pressure tie-break」窄修沒有退化。
- 但 `defense-choice: receive` 本身不是立即終局；真正 Lost 在兩個決策後，現有 guard 看不到。
- 當搜尋認為兩條線最終都輸時，缺少「先延長比賽／先通過當前判定」的次級排序。

> [Codex 2026-07-21] 工程假說：終局保護需從單步 `decisionImmediatelyLosesSetOrMatch` 擴到防守路線的短程生存性，或在 defense-choice 全零 tie 中加入「能確定通過本次 OP」的優先級。此輪未修改。

## 先帶去討論的打法調整

以下是報告後可討論的方向，不在本輪直接定案成硬門檻：

1. **Set 1 棄牌及川取消自動發動。** 先問 +1 是否跨防守線、是否拆下一條三職鏈。
2. **保留 PR 及川的正式收割定位。** 同時做到 OP7+ 與對手手牌 6→4 時，是高價值發動。
3. **固定「先產生資訊，再付棄牌成本」的時序。** 尤其 `お前達は 強いよ` 與岩泉成本同回合出現時。
4. **OP0–1 優先走可完成反擊的接球線。** 不用萬用及川做只回 OP0 的攔網。
5. **第五 Set 前開始看有效角色鏈，不只看手牌張數。** 牌庫必然很薄，終局要保的是接—托—異名攻與一個增益來源。
