## 1 牌組營運：前中後期策略

（依 33 場實際曲線：手牌中位 T1–2＝8 → T3–5＝6 → T6+＝2；事件區平均僅 1.1 張；BA 每場約 1.6 次）

### 前期（每 Set Turn 1–2）——「先讓一手」是結構性弱點
- 本牌組發球 OP 平均只有 **1.38**（對手平均 2.44；青葉城西是 3.80）。唯一像樣的發球手是星海 023〔發4〕。**別浪費資源去撐發球回合**：發球回合的目標只是「不虧資源地過渡」，用 022 宮侑／024 星海這種之後上場位不衝突的名字發球即可。
- 真正的前期任務是**名字鏈佈局**：這套牌只有 6 個角色名（影山/星海/宮侑/古森/佐久早/千鹿谷），而「托≠接同名、攻≠托同名」。從第一手就要想好「這 Set 的接球位給誰、托球位給誰」，別把同名的兩張都卡在必經之路上——**33 場裡 27 次失 Set 是『未能登場』，多數不是沒牌，是名字對不上**（失 Set 時手牌中位還有 7 張）。
- 接球位優先擺**影山 020**（BA 待發）而不是無腦擺古森 029〔接6〕：coach 掃描裡「登場影山→建議登場古森」12 次，但那多半是短期 DP 最大化；influenced by 你的 combo 佈局時，先看「這回合對手 OP 需要 6 嗎」——對手發球/低 OP 回合擺影山（接5 夠用）是**你比 AI 更有前瞻性的正確線**，只有對手 OP≥6 的回合才必須讓位給古森。

### 中期（Turn 3–5）——燃料管理是勝負手
- 本牌組三個核心技能（影山 BA、星海+3、佐久早攔+2）**全部吃「事件區的ユース卡」當燃料**，但實測你的事件區平均只有 **1.1 張**——燃料常態枯竭。你的習慣是接球回合順手把雲雀田/火焼打掉換抽（它們同時也是進事件區的燃料，這沒錯），**錯的是接著馬上用星海/佐久早把燃料燒掉換 +2/+3 的小數值**。
- **燃料使用優先序**（依實戰失分型態）：影山 BA（+4 攻且下回合 OP 不降）＞ 千鹿谷保命後的接球 buff ＞ 星海攔網位 +3（對爆發軸）＞ 星海攻擊 +3 ＞ 佐久早攔 +2。coach 資料佐證：「選項：攻擊點數 → 建議：攔網點數」8 次（星海 023 的參數選擇你習慣選攻，搜尋在防守輪要你選攔）。
- 攻擊線：中期你的 attack OP 平均 5.61（對手 4.10），**優勢期就在 T3–5**。宮侑 021 的 3-Guts 技能（托+2＋回收事件）是把「Guts→燃料」的轉換器，Guts ≥6 時優先開——這也是新 gameplan profile 的目標之一。

### 後期（Turn 6+）——天花板誠實學
- T6+ 你的手牌中位只剩 2，attack OP 掉到 4.16。**這套牌打不了長 Set 消耗戰**，後期只有兩條贏線：(1) 千鹿谷 030 對 OP≥8 的「直接結束攔網階段」保險（前提：全員ユース＋他在攔網位——中期就要把他擺好，7 次「登場千鹿谷→建議登場星海」的分歧多發生在你太晚才想擺他）；(2) 死局資源管理——判定注定失敗的球，**登場你之後最不需要的卡去送，或干脆不登場**，把古森/影山留給下一 Set。samples=25 復驗的鐵證：S4T5 對 OP7（最高只有古森接6，怎麼站都輸），你從手上又丟了一張古森進去（4%），正解是丟星海 023 保住古森（36%）。
- 「AI 勸你棄 Set」的建議**不要照單全收**：33 場中出現 59 個「AI 建議主動 Lost、你選擇續打」的段落，你續打後**贏下該 Set 31 次（52%）**。你的續打判斷整體是加分的（詳見報告 19 §B4——這是引擎價值函數對 grind 線悲觀）。判斷準則留給自己：**「續打要花的手牌 ≤2 張、且下一 Set 我先發或對手牌庫更薄」才續打**，否則收手。

## 2 你 vs 電腦：共同分歧模式

### 你更有前瞻性的（保留）
1. **拉鋸局續打**：如上，52% 逆轉率，AI 的棄局建議過度悲觀。
2. **影山接球位佈局**：AI 常要你擺短期最大 DP（古森），你為 BA 留影山的佈局在對手低 OP 回合是對的。
3. **技能該開就開**：「接受效果→建議拒絕」28 次中，18 次發生在你最終贏下的 Set。引擎已知對技能點數估值偏低（L0007），這類建議參考價值有限。

### 該改的壞毛病
1. **同名鏈不規劃（最痛）**：27 次未能登場失 Set＋大量「登場A→建議登場B」分歧的共同根因。每 Set 開局花 5 秒排「接/托/攻的名字鏈」，這是本報告最值錢的一條（已寫入 lessons L0009）。
2. **事件卡自動駕駛**：「使用ドンッ→建議 Pass」13 次、「使用雲雀田→建議 Pass」11 次，同時「Pass→建議使用周りの上手さ/火焼」共 16 次——**你不是用太多，是時機錯位**：習慣性在自己的節奏回合把抽牌事件打光（事件區燃料反而在錯的回合被星海燒掉），真正需要 +1 接球度過防守輪時手上沒事件。改法：**每回合打事件前問「這張留到防守輪會不會更值」**。
3. **勝 Set 後的第二 Set 慣性**（Set 2 勝率 48%）：贏 Set 1 後手牌處於劣勢期，前 2 回合克制技能與事件、只做名字鏈佈局，等 interval 補牌後再開節奏。
4. **死局丟錯牌**：判定救不回來的球要「送最便宜的」，你常送掉下一 Set 的核心（古森/影山）。
