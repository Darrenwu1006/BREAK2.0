## 問題定義

這輪不問「哪個張數勝率最高」，而問：

- `HV-PR-059 宮・古森` 出場時，是否真的把 Set 救回來？
- 同一對手、同一 seed 下，1/2 張相對 0 張是否穩定多拿 Set？

## 判斷

[Codex 2026-07-09] 若使用者的決策門檻是「沒有顯著正向加分就不放」，目前證據不足以要求一定要放。

較精準的說法是：

- 2 張有小樣本正向行為訊號，值得測，但還沒證明是必要卡。
- 1 張比較像低風險保險，卻沒有證明 PR 本身能救回 Set。
- 0 張可以作為保守結論，尤其若真人體感不是常因 `宮侑 / 古森` 名分流斷線而輸。

因此，若現在要選一個實戰方向，我會建議：

1. 先以 0 張為主線，不急著把 PR-059 放回正式版。
2. 把 2 張保留為「待真人體感 A/B」版本，而非直接採納。
3. 下一輪優先看實際對局中的敗因是否真的是 name-chain 斷線；如果敗因更多是 Guts 使用、攻擊時機、防守保牌、事件使用節奏，那就應優先優化打牌方式。
