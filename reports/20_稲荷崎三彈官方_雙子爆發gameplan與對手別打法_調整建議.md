## 1 牌組本質：三個必須內化的資源數學

1. **どんぴしゃり combo 的彈藥在 Guts 裡**：087 的三段效果是「從自己 Guts 登場侑到托球／治到攻擊」＋能力+1。**Guts 堆裡沒有雙子＝087 只是張抽 1**。所以付 Guts 成本時要「優先用多餘的雙子付」，把侑/治 存進 Guts 當彈藥；反過來，把赤木/北当 Guts 燒掉、雙子囤手上，就是把 combo 拆了。
2. **Guts 三頭馬車**：016 侑（3 Guts：抽1＋托+2）、020 治（3 Guts：攻+3，經 087 登場再+1）、024 北（棄1＋3 Guts：回收事件區）。全開一輪要 6–9 Guts。實戰那場你支付 15 Guts（對手 11）——**每 Set 你只養得起一次「全額 combo 回合」，選好那一回合，其餘回合打半價線**（只開 020、或裸 087）。
3. **8 張 cantrip 事件＝自己磨自己**：今日×2、黑須×3、087×2、絶望×1 全部帶抽 1——爽，但等效把 40 張牌庫變 32 張。實戰那場 Set4 結束**牌庫剩 1**、Set5 抽乾而死。規則又要求**進攻回合接/托/攻三格都要從手牌強制登場**，長局的手牌消耗是剛性的。**這套牌結構上必須在 Set 內速戰（Turn 5–6 前終結），拖進長 rally／搶五局＝死線**。這也解釋了為什麼「AI 勸棄」哲學對這套牌反而值得多聽一點：死 Set 早棄、把牌留給下一 Set，比其他牌組更重要。

## 2 早中後期 gameplan

### 前期（每 Set Turn 1–2）：鋪彈藥，不是搶分
- **發球手用 040 侑〔發5〕**（或 016），發球 OP 5 對白板接5線有壓力但別加碼——這套沒有 091 俺のサーブ（發球變 6）的版本，發球是騷擾不是贏點。
- 開局最重要的兩件事：(a) **把接球線站穩**（赤木 034〔接6〕優先、046〔接5，對手發球OP≥6 時+2〕看對手發球強度選）；(b) **開始存 Guts 彈藥**——付款順位：多餘雙子 > 小作 035（他本來就是棄牌技） > 其他。北 024/043 和赤木盡量別進 Guts。
- 事件節奏：前期只打「黑須」（抽+接球 buff，防守回合順手）；**今日何をする和 087 留著**——今日是 combo 回合的托球加成，087 是 combo 本體，前期打掉＝把中期的爆發回合拆成散件。coach 資料佐證：「使用今日→建議 Pass」4 次（-35%avg）、「使用 087→建議 Pass」3 次，都是提前空放。

### 中期（Turn 3–5）：一 Set 一次的「全額回合」
- 理想 combo 回合長這樣：托球位已有侑（或用 087 從 Guts 拉）→ **087：Guts 治上攻擊位 → 020 技能（3 Guts）攻 2+3+1=6 → 016 若也經 087 上場（3 Guts）托 3**（＋今日再+1）→ **OP 8–10**，同時吃到兩個 rider：對手下回合**ワンタッチ與接球手牌技無效**（016）、**手牌攔網手最多 2 名**（020）。這兩個 rider 正是對音駒（灰羽ワンタッチ、これが繋ぐ）和伊達（攔網海）的內建對策——**combo 不只是數值，是帶著封鎖的數值**，時機選在對手防守資源最厚的回合反而最賺。
- 沒彈藥的回合打半價：裸 020（攻5）配 03-022/040 侑托 2 → OP 7 也夠殺大多數白板接5。**別為了湊滿 combo 把手牌掏空**——記住三格強制登場，你的手牌底線是「下個防守輪 + 下個進攻輪的登場需求」≈ 3–4 張。
- 024 北信介的回收（棄1+3Guts 拿回事件區的稲荷崎卡）**只在「拿回來的是 087/今日」時划算**，拿黑須＝虧。coach 佐證：「登場北024→建議不登場」6 次（-37%）——他是引擎不是身體，別當白板鋪。

### 後期（Turn 6+／Set 4–5）：資源終局學
- 進入 Set 4 前看一眼牌庫：**低於 12 張就要改打「省牌模式」**——cantrip 事件不再見一張打一張（每張抽牌都在加速自己的死期）、優先用場上既有角色撐 rally、死局早棄（本牌組棄局的期望值比別家高，見 §1-3）。
- 決勝局（雙方 Set 區 0）**不存在「留到下一局」**，手牌全部是登場權：算好「這回合接/托/攻要 3 張」再決定要不要打事件換抽。實戰 Set5 的死法（牌庫 0 手牌 1 托球登不出）在 Turn 3 就注定了——當時連打兩張 cantrip 沒有必要。
- 山形/絶望類「從 Guts 拉北信介上接球」（093）是後期免手牌的防守補丁，**留到手牌 ≤2 的防守輪再開**，前期打掉＝丟掉一條命。

## 3 對手別打法

### vs 音駒（二口干擾／三彈官方）——模擬 45%／75%（調整A後 50%／75%）
