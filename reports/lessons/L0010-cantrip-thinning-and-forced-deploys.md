抽替（cantrip）事件每張都「抽 1」很順手，但等效把 40 張牌庫變 40−N 張：稲荷崎三彈官方帶 8 張 cantrip，實戰 Set 4 結束牌庫剩 1、Set 5 抽乾，托球位強制登場登不出直接敗北。規則「進攻回合接/托/攻三格都要從手牌登場」讓手牌消耗是剛性的，牌庫見底＝斷登場＝死。

**通則**：
1. 組牌時把 cantrip 數當「自磨速度」看，不是免費的。
2. 對局中進入後段（牌庫 <12）改打省牌模式：cantrip 不再見一張打一張，每張抽牌都在加速死期。
3. 這類牌組的贏線在 Set 內速戰；死 Set 早棄的期望值比一般牌組高（把登場權留給下一 Set）——AI 的勸棄建議（L0008）對這類牌組的參考價值相對高。
4. 唯一例外：對攔網軸（伊達）這種會把 rally 拖長的對手，節流要更早開始。
