硬規則「托球不可與接球同名、攻擊不可與托球同名」讓少名字牌組（ユース只有 6 個角色名）與多版本同名牌組（青葉城西的及川×3 版本）的失 Set 大宗都是「未能登場」（youth 27 次、aoba 36 次），**且失 Set 時手牌中位還有 7 張——不是沒牌，是名字對不上**。

**通則**：
1. 每 Set 開局（與 interval 補牌後）花幾秒排定「這 Set 接球位/托球位/攻擊位各給哪個名字」，同名的兩張不要同時卡在必經之路。
2. 多版本同名卡先定義各版本的專屬崗位（如及川：058 白板站發球、033 留給開技能的回合、056 只為回收岩泉上托球），不要把技能版當白板燒。
3. 判定已注定失敗的死局，登場（或不登場）以「保住下一 Set 的登場權」為準——送參數最無用的牌，把核心接球體留下（samples=25 復驗實例見報告 17 §1 後期、報告 18 §1 後期）。
