## 2. 青葉城西真正的資源不是手牌張數

這副牌有 11 張及川、8 張岩泉、5 張国見、6 張渡、2 張金田一與 8 張事件。高同名密度讓主軸很穩，但也產生兩個必須主動管理的風險：

1. **手牌很多，不代表能接住。** 基礎高接球主要集中在国見與渡；白鳥沢 OP6 出現時，普通 R5 仍會失敗。
2. **角色很多，不代表能走完三段鏈。** 托球與攻擊不可同名；手上若只剩及川，即使有三張角色，也可能在及川托球後完全沒有合法攻擊手。

因此，本報告後續把資源拆成四種，而不是只看手牌數：

- **接球上限**：這一回合最高能做到多少 DP。
- **完整身體鏈**：能否依不同名限制完成 receive、toss、attack。
- **可支付 Guts**：是否保有啟動国見、岩泉、及川等技能的 3 Guts 門檻。
- **終結資源**：是否同時有托球加值、岩泉／高攻擊手與可棄／可回收的卡。

## 3. 對白鳥沢：先通過 OP6–7 的防守考試

### 為什麼可以贏

**勝場的第一個共同點不是先攻得更兇，而是有辦法守住白鳥沢的高壓球。**

- 10:56 場 Set 2 第 80 步：渡親治把 DP 拉到 7，精準守住白鳥沢 OP7。
- 11:48 場 Set 2 第 77 步：DP7 守住 OP6。
- 11:48 場決勝 Set 第 186 步：事件區已累積 8 張，国見技能與資源把 DP 推到 9，守住 OP7。這一步使白鳥沢手牌只剩山形與瀬見兩張，攻守交換正式反轉。

**第二個共同點是沒有把 OP4–5 誤認成終結，而是等白鳥沢的實際接球品質下降後再打 OP6–8。**

- 10:56 場 Set 3：岩泉攻擊形成 OP6；白鳥沢當時最佳接球只剩牛島 R5，直接穿防。
- 同場 Set 4：再次以 OP6 對上牛島 R3，完成比賽。
- 11:48 場決勝 Set：守住 OP7 後，白鳥沢手牌只剩兩張；青葉城西以岩泉做 OP7，跨過山形 R6 收尾。

**所以白鳥沢對局的贏法不是「一直棄牌、一直壓手」。** 真正順序是：

`建立事件／Guts → 用成長接球手過 OP6–7 → 確認山形或防守事件不在手上／已被迫落場 → 岩泉 OP7–8 終結`

### 為什麼會輸

10:49 的 1:3 敗局提供了三種不同死法：

1. **Set 2：長交換後只抽到 R1 及川。** 第 33 步曾以 DP6 守住 OP6；但後續雙方把手牌投入完整三段鏈，我方一度歸零。第 65 步面對 OP3 時只剩一張 R1 及川，屬於前面交換累積出的資源死局，不是最後一手才突然犯錯。
2. **Set 3：R5 正面撞上 OP6。** 第 92 步国見做到 DP5，但白鳥沢仍以 OP6 穿過。手上雖有五張牌，沒有能在當下補到 6 的可用線。
3. **Set 4：八張手牌仍無法接 OP6。** 第 98 步手牌多達八張，但沒有當下能成立的 R6／加值接球線，白鳥沢瀬見的 OP6 發球直接結束比賽。這是「手牌數量充足、接球品質不足」最清楚的反例。

11:48 勝場失掉的 Set 也重複同一模式：

- 第 92 步只剩一張 R0 及川，面對 OP2 仍因身體資源斷裂而倒下。
- 第 143 步即使手上仍有四張牌，最高普通接球仍只有 R5；面對 OP6，選岩泉 R1 或国見 R5 都無法改變結果。

### 對手資源的全觀判讀

白鳥沢牌表本身就針對「6」這個門檻設計：

- 山形 R6 ×5，是最直接的 OP6 防線。
- 另一版山形 R5 ×2 可在後期支付 3 Guts 變 R7並回收角色。
- 牛島可支付 2 Guts，從 R2 變 R6。
- 鷲匠事件能抽牌並提供 R+1，進一步棄無技能角色後可再 +2。
- 瀬見可形成 OP6 發球；牛島則反覆形成 OP6–7 攻擊。

這解釋了為什麼今天對白鳥沢 15 次攻擊中，有 8 次仍落在對手當下最佳單卡接球範圍內。**OP5 以下通常只是交換，不是終結；OP6 也必須先確認山形／事件／Guts是否仍在線。**

納入 7/17 同版本的 4 場後，對白鳥沢總計 5 勝 2 敗、Set 17:13；13 個失 Set 中仍是未能完成登場 7、判定失敗 6。這證明白鳥沢長期同時考驗接球上限與身體續航，並非今天單場牌序造成。

## 4. 對音駒：分數不是主要死因，三段鏈才是

### 為什麼可以贏

**四場勝利的共同收尾，是先讓音駒把高接球角色與功能角色落到場上，再用 OP7–9 攻擊它剩下的手牌品質。**

- 11:09 對二口干擾：Set 3 以 OP6跨過夜久 R5；Set 4 最後以 OP9收尾。終結前對手四張手牌只有夜久 R5、手白、黑尾與一張事件，已無法承受 9。
- 11:20 對二口干擾：決勝 Set 我方牌庫已空，仍保留及川—岩泉終結鏈；第 194 步岩泉形成 OP7。對手四張手牌包含兩張事件、孤爪與二口，沒有可接 7 的角色。
- 11:39 對三彈官方：Set 3 以 OP8、Set 4 以 OP7收尾。終局對手雖有四張手牌，但只有低接球黑尾、灰羽、孤爪與事件。
- 17:03 對三彈官方：決勝 Set 先用及川支付 3 Guts 洗回三張手牌並抽 4，再由岩泉棄牌加攻，形成 OP7；音駒抽牌後有五張手牌，但其中三張是事件，剩餘角色只有灰羽 R2與海 R4，因此仍無法接球。

**這說明你不是靠單純手牌破壞贏音駒，而是在贏「手牌品質」。** 音駒手牌數看似還有 4–5 張，只要高接球角色已經落場、剩餘手牌偏事件或低 R，OP7 就是實際終結線。

### 為什麼會輸 Set

今天對音駒共失 6 Set，全部被工具記為未能登場；逐盤檢查後可再細分為三類：

1. **身體數不足**
   - 11:09 第 116 步：只剩一張事件與一張 R1 及川，面對 OP3，既接不住也不可能完成三段鏈。
   - 11:20 第 44 步：音駒手牌已是 0，看似即將勝利；但我方手上只有事件，抽到一張岩泉後用於接球，立刻在托球區斷鏈。對手沒牌，不代表你已經有三個身體。
   - 11:20 第 159 步、11:39 第 57 步、17:03 第 103 步：面對 block return OP0時仍只有兩個角色。點數完全不是問題，但兩張角色無法完成 receive、toss、attack三個登場。

2. **同名鎖死**
   - 17:03 第 27–31 步：接球後手上是三張及川與一張 `俺も思った☆`。及川托球後，事件又抽到一張及川；最後三張手牌仍全是及川。因攻擊角色不可與托球角色同名，即使手上有三張角色，也沒有合法攻擊手而失 Set。

3. **牌庫與回收成本累積**
   - 對二口干擾的兩場，我方結束時牌庫分別只剩 2與0；對三彈官方的最長一場也在決勝 Set 牌庫歸零。
   - 二口效果存在時，抽牌以外的加入手牌會額外磨掉牌庫頂 3 張。及川回收岩泉、事件區回手等動作不再是免費續航；是否值得啟動，要把三張牌庫稅算入交換。

### 對手資源的全觀判讀

兩版音駒的防守方式不同：

- **二口干擾版**透過黑尾攔網、夜久／海接球與大量抽牌事件拖長回合，再用二口懲罰非抽牌的回收。它不一定以高 OP 殺你，而是讓你在 OP0–3 的回球裡自己耗完三個身體。
- **三彈官方版**有夜久 R6、犬岡／山本 R5，以及 5 張 `これが"繋ぐ"ということだ`，可把接球值直接設為 7。OP6 很常只是讓它交出一張防守資源；真正穩定的終結仍是確認其手牌高 R 已耗盡後打 7以上。

所以對音駒不能只問「這球能不能接住／打穿」，還要問：

- 這回合結束後，我是否仍保有三個不同用途的身體？
- 如果用及川托球，手上是否還有非及川攻擊手？
- 對手的高 R 是仍在手上，還是已經落在接球區／Guts／棄牌區？
- 二口限制在線時，這次回收值不值得三張牌庫？

## 5. 跨場因果：你為何贏、又為何輸

### 可複製的勝因

1. **把 Guts 留給能改變生死門檻的技能。** 對白鳥沢，DP5→7／9是真正的 Set 差；對音駒，及川 3 Guts 回收／洗牌與国見補牌讓終結鏈不斷。
2. **岩泉技能用在確定的終結窗口。** 當對手手牌已降到 4以下且高接球角色落場，棄 1 換 +2與禁補牌能直接形成不可逆壓力。
3. **能接受非致命攻擊只是交換。** 多場勝局先用 OP3–6逼出山形、夜久、攔網或事件，最後才打 7–9。這些早期攻擊只有在換到對手身體時才有價值。
4. **長局中沒有因牌庫接近 0 就停止執行終結線。** 兩場對音駒的決勝局都是我方牌庫 0仍獲勝；關鍵不是剩幾張牌庫，而是當前手牌能否完成最後三段與 OP7。

### 可控制的敗因與風險

1. **把手牌張數誤認成防守安全。** 對白鳥沢八張手牌照樣會被 OP6發球終結；要數最高 DP，不是總張數。
2. **只檢查當下接球，不檢查完整三段鏈。** 對音駒至少四個失 Set在 OP0–3下發生；它們輸在托球／攻擊身體不足，不是接球點數。
3. **沒有提前管理卡名分布。** 及川 11張讓主軸穩定，也會製造「及川托球後全手同名」的隱性死局。看到手牌剩 3–4張時，要把不同卡名視為獨立資源。
4. **回收與補牌可能加速牌庫死亡。** 尤其對二口，非抽牌加入手牌是三張牌庫稅；若這次回收不能換到續命或終結，可能只是把下一個 Set的資源提早燒掉。

## 7. 討論前的暫定營運原則

> [Codex 2026-07-18] 以下保留為分析當時的假說；使用者補充實戰意圖後，已由正式備忘錄取代。

### 對白鳥沢

- 普通 R5不是安全防線；看到對手可做 OP6時，先確認是否留有 3 Guts與可成長接球手。
- OP5以下預設視為資源交換；若說不出要逼掉山形、事件或幾張身體，就不值得額外棄牌加攻。
- 山形 R6仍可能在手時，OP6不是穩定終結；以 OP7為基本目標，或先把山形逼落場。
- 成長接球手與事件區是這個 matchup 的生命保險，不要只為提早一球 OP而拆掉。

### 對音駒

- 每次選接球前先數完整 `接—托—攻` 三個身體；block return OP0也不能省略這一步。
- 及川準備托球時，至少保留一張非及川攻擊手；「三張角色」不等於「三個可用身體」。
- 對二口，非抽牌回手要附加「牌庫 −3」再評估；只為增加手牌數、不解決續命或終結的回收先不要做。
- 終結判斷看對手最高實際 R，不看手牌總數；事件多、角色 R≤5時，OP7通常已是窗口。

## 8. 討論後的意圖確認與修正

1. **音駒同名鎖死不是攻擊階段才發現。**使用者已知道缺少非及川攻擊者，連用事件是主動搏抽牌；真正可控制的決策更早發生在起手／第一球：及川發球技能習慣性棄岩泉，把當前異名身體換成尚未確定的未來回收。
2. **Guts必須按區域分開。**接球、托球、攻擊 Guts多數不能混用；今日接球型岩泉沒有出現「在手、對手三張以下、而且確實需要 R8」的有效窗口，因此未發動不是玩家漏開。
3. **第三彈國見是刻意保留的後期防線。**白鳥沢決勝 Set在事件區 7 張、接球區 4 Guts時，以國見 R8＋事件形成 DP9守 OP7；這是可複製的正確營運，不是偶然摸到。
4. **瀨見 OP6終局當下確實無解，但前一 Set有循環機會。**兩張接球事件仍在牌庫；六張渡中兩張在接球 Guts、兩張在棄牌、兩張在牌庫。若前一 Set以技能及川多棄一張重複牌，維持同樣 OP5並讓對手棄牌，Lost後可藉 Interval多看一張；簡化反事實中會在瀨見發球前看到回收事件並打開渡 DP6線。
5. **音駒 OP4／7門檻得到實戰確認。**今日 4 次 OP4全部收取 2名攔網者；3 次 OP7有 2次迫使接球、1次收取 2名攔網者；8 次 OP6仍讓對手在攔網／接球間保有彈性。

## 9. Caveats and Assumptions

- 音駒主樣本沒有整場敗局，因此本報告只能分析失 Set、近敗局與高風險勝局；不把 4:0誤寫成「對音駒的敗局模式」。
- 全觀盤面可看到對手真實手牌；本報告只用它解釋實際資源交換。討論當下決策時，仍會區分玩家可知公開資訊與賽後全知資訊。
- Replay 的 `uid=null` 會被摘要標成「未能登場」，其中可能包含玩家在已知無完整後續時主動不登場。本文已回看代表盤面，不把所有 `no-deploy` 一律當成操作失誤。
- 「攻擊高於最佳單卡接球」只比較當下可見的單卡接球上限；攔網、事件、技能與後續抽牌仍可能改變實際結果，因此只作方向性對照。
- Coach 只在四個代表步驟使用 40 samples、10%門檻，沒有發現明顯劣於替代線的實戰選擇；此結果只能輔助排除大錯，不能當精確勝率或最優性證明。
- 對手由現行 AI操作；卡片資源結構可直接沿用到真人對局，但對手的心理、保牌與風險偏好不應直接等同你的朋友。
